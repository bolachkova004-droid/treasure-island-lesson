# Промпты для ChatGPT: красивый дизайн уроков

Здесь три промпта:

1. **Редизайн страницы.** Вставляете промпт и прикрепляете HTML-файл: `index.html`, `chapter-4.html` или `a2-words.html`.
2. **Иллюстрации.** Картинки для шапок заданий в едином стиле.
3. **Проверка результата.** Короткий промпт, который ловит поломки после редизайна.

Главное правило: ChatGPT должен менять **только внешний вид**. Если он переименует `id`, классы или `data-*` атрибуты, перестанут работать кнопки, проверки и сохранение прогресса.

---

## 1. Редизайн страницы

Прикрепите HTML-файл и вставьте:

```
Ты — ведущий UI-дизайнер образовательных игр. Перед тобой интерактивный урок английского (уровень A2–B1) по роману «Остров сокровищ» — один HTML-файл со встроенными CSS и JavaScript. Сделай его по-настоящему красивым, но НЕ сломай работу.

СТИЛЬ
- Настроение: «приключенческая книжка-игра» — тёплая, сказочная, немного морская. Ориентиры: иллюстрации в духе Studio Ghibli и современные детские приложения (Duolingo, Headspace), но для подростков и взрослых — без «детсадовости».
- Палитра (задай токенами в :root): глубокий морской синий #16324F (заголовки, тёмные плашки), бирюза моря #1FA6A0, пергамент #FFF6E0 (фон карточек), тёплое золото #FFB020 (награды, звёзды), коралл #E5533D (ошибки, акценты), мягкий зелёный #4CC25A (верно). Текст — #233A57, вторичный — #5D6F88.
- Шрифты Google Fonts: заголовки — «Fraunces» или «Rubik» 700–800, текст — «Nunito» 600. Крупный кегль: основной текст 17px, заголовки листов 32–44px.
- Формы: скругления 18–26px, «пухлые» кнопки с нижней тенью (0 5px 0 более тёмный тон), лёгкая бумажная текстура или мягкий градиент неба на фоне страницы.
- Микроанимации: появление листа (fade + сдвиг 12px), лёгкий «прыжок» кнопки при нажатии, конфетти/искры при верном ответе (CSS, без библиотек). Всё отключается при prefers-reduced-motion.
- Иконки — эмодзи или простые inline SVG в одном стиле. Никаких внешних картинок, кроме уже встроенных.

ЧТО ВАЖНО СОХРАНИТЬ (иначе урок сломается)
- Не переименовывай и не удаляй ни один id, class, data-атрибут и aria-атрибут, которые встречаются в JavaScript. Можно ДОБАВЛЯТЬ свои классы и обёртки, но только если JS не ищет элемент через родителя.
- Не меняй JavaScript-логику, тексты заданий, ответы и ключ localStorage. Если без правки JS не обойтись — перечисли такие места отдельно и объясни.
- Не подключай фреймворки (Tailwind, Bootstrap, React). Только чистый CSS внутри <style>.
- Файл должен остаться одним самодостаточным HTML.

АДАПТИВНОСТЬ И ДОСТУПНОСТЬ
- Идеально на iPhone (ширина 375px): никакой горизонтальной прокрутки, кнопки не меньше 44px, поля ввода 16px (чтобы iOS не зумил), учёт safe-area.
- Контраст текста не ниже WCAG AA, видимый фокус для клавиатуры.
- Добавь тёмную тему через @media (prefers-color-scheme: dark) на тех же токенах.

РЕЗУЛЬТАТ
1. Сначала коротко (5–7 пунктов) опиши концепцию дизайна.
2. Затем отдай ПОЛНЫЙ готовый HTML-файл целиком, без сокращений и без «…остальной код без изменений».
3. В конце — список всего, что ты изменил, и подтверждение, что id/классы/data-атрибуты не тронуты.
```

**Если файл слишком большой** (`index.html` весит около 320 КБ из-за встроенной картинки): попросите ChatGPT прислать только новый блок `<style>` и список HTML-правок. Новый `<style>` потом вставьте в файл вместо старого.

## 2. Иллюстрации для шапок заданий

Сначала задайте общий стиль, потом просите отдельные сцены. Тогда все картинки получатся из одной книги.

**Общий стиль, первым сообщением:**

```
Мы делаем серию иллюстраций для урока по «Острову сокровищ» Стивенсона. Единый стиль для всех картинок: тёплая книжная акварель + чистые контуры, как в современной детской книге о приключениях; мягкий свет, лёгкая зернистость бумаги; палитра — глубокий морской синий, бирюза, пергамент, тёплое золото, коралловые акценты. XVIII век, побережье Англии. Без текста, букв и логотипов на изображении. Формат 16:9, главный объект смещён вправо, левая треть спокойная — там будет заголовок. Персонажи: Джим Хокинс — мальчик 12 лет, русые волосы, простая рубашка и жилет; его мама — худощавая женщина в тёмном платье и чепце; Билли Бонс — старый моряк со шрамом от сабли на щеке, косичка, синий потёртый камзол; слепой Пью — сгорбленный, в рваном плаще с капюшоном, с палкой и зелёной повязкой на глазах. Подтверди стиль одной фразой, картинку пока не рисуй.
```

**Сцены главы IV:**

```
Сцена 1 (обложка главы): ночь, комната трактира «Адмирал Бенбоу» при свече. Джим и мама стоят на коленях перед открытым морским сундуком с выжженной буквой «B» на крышке. Внутри — сложенный костюм, пистолеты, ракушки, свёрток в промасленной ткани и холщовый мешочек, из которого сыплются старинные золотые монеты. Окно с туманом и луной. Тревожно, но уютно от свечи.
```

```
Сцена 2: туманная деревушка у моря ночью, в окнах свечи. Мама Джима просит мужчин о помощи, они отводят глаза и пятятся. Джим держит маму за руку.
```

```
Сцена 3: мама Джима при свече считает монеты разных стран на столе, Джим прислушивается к двери. За заиндевевшим окном на дороге — силуэт слепого с палкой.
```

```
Сцена 4: лунная ночь, каменный мостик через ручей. Джим тянет ослабевшую маму под арку моста, прижимая к груди свёрток. Вдали — огни трактира и тёмные фигуры с фонарями.
```

**Как вставить картинку в урок:** сохраните её в формате WebP шириной около 1400px и положите в репозиторий рядом с HTML, например `img/ch4-chest.webp`. Потом попросите меня или ChatGPT вставить её в шапку нужного задания.

## 3. Проверка после редизайна

```
Сравни старый и новый HTML. Перечисли: (1) все id, class и data-атрибуты, которые есть в JavaScript старого файла, но пропали или изменились в новом; (2) места, где на ширине 375px может появиться горизонтальная прокрутка; (3) текст с контрастом ниже WCAG AA. Если всё в порядке — так и скажи.
```

Перед заливкой нового файла на сайт откройте его в браузере и пройдите хотя бы одно задание на каждом листе: ответьте, нажмите «Проверить», перезагрузите страницу и убедитесь, что прогресс сохранился.
