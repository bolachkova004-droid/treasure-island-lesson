# Заветье в Kling AI

Живые портреты и кат-сцены. Промпты с кнопками «Скопировать» — на странице «Заветье в Kling» (артефакт). Здесь — то, что нужно для сборки.

## Кадры
`python3 tools/kling_frames.py` собирает стартовые кадры из картинок игры в `kling/`:
- `kling/portraits/p_*.jpg` — 1080×1920, портрет во всю ширину кадра, низом к низу, на ровном тёмном фоне `#1a1613`;
- `kling/scenes/c_*.jpg` — 1920×1080 из фонов; `*_start` / `*_end` — пара для появления духа (стартовый и конечный кадр).

## Ролики → игра
1. Ролики из Kling называются по ключу: `p_grunya_warm.mp4`, `c_noon.mp4`.
2. `python3 tools/video_prep.py ПАПКА` сжимает их в `video/КЛЮЧ.webm` (VP9) и `video/КЛЮЧ.mp4` (H.264, Safari) и обновляет `VIDEOS` в `js/video.js`.
   Портреты: 540×960, без звука (~100–150 КБ на 5 с). Сцены: 1280×720, звук сохраняется.
3. При публикации добавить файлы `video/*` в `files`.

## Как это работает (`js/video.js`)
- **Портрет:** видео лежит поверх картинки в слоте портрета; маска — альфа самого портрета (`mask-image`), поэтому тёмного фона не видно. За 0,5 с до конца ролик растворяется в неподвижный портрет и начинается снова: первый кадр совпадает с картинкой, шва нет.
- **Кат-сцена:** `VCUTS` — какие ролики играют перед какой сценой, один раз за игру (`st.tut[key]`). Ролик главнее 3D-сцены. Нет файла или браузер не может его открыть — игра идёт, как раньше.

| Ключ | Где играет |
|---|---|
| c_arrive_1, c_arrive_2 | `p_road` — первый раз на дороге |
| c_house | `p_house_in` — первый вход в дом Аглаи |
| c_noon | `noon` — Полудница появляется |
| c_leshy | `leshy` — первый раз в ельнике |
| c_izba | `forest_night` — изба на порогах |
| c_stop | `fr` — лесная остановка, 6:38 |
| c_rusal | `river_rite` — вместо 3D, если будет ролик |
| c_bus | `bus_sunday` — автобус в воскресенье |
