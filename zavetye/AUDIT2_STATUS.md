# Заветье: второй аудит — конкретные исправления и типографика

Сверка с документом «Заветье — конкретные исправления». Что сделано и где это в коде.

## 0–1. Типографика

| Пункт | Что сделано |
|---|---|
| Убрать Cormorant Garamond | Удалён. Титулы и главы — **PT Serif Caption**, обычное начертание (`--display`). |
| Убрать Caveat как системный почерк | Caveat (`--note`) остался только у почерка Аглаи (её записки, надпись на посылке, пометки красными чернилами в тетради Гриши), у найденного письма синей ручкой и у Вариного рисунка. Мысли Анны, подсказки, тосты, улики, тетрадь, English — книжный шрифт. |
| Максимум 2 семьи + mono | Текст и интерфейс — **PT Serif** (`--body`), титулы — PT Serif Caption (`--display`), билеты и машинопись — PT Mono (`--mono`). Четыре роли: body / display / note / mono (`css/game.css`, `:root`). |
| Меньше курсива | Курсив только у мыслей Анны, её реплик в выборе, цитат-показаний, подзаголовков. Кнопки, имена, режимы, время — прямое начертание. |
| Меньше разрядки | Заголовки и метки: .14–.2em → .03–.07em. |
| English без «ручного» шрифта | Английский набран тем же шрифтом, что и текст; ключевая конструкция подчёркнута красным карандашом. |

## 2. Приёмы «сгенерированного дизайна»

| Пункт | Что сделано |
|---|---|
| Случайные наклоны | Убраны у меню, подтверждения, улик, записей, тезисов, тостов, поверий. Лёгкий наклон остался только у вклеенного фото, конверта и штампа. |
| Меньше бумажности | «Заветье изменилось», поверье, версия в разговоре, тост — типографические слои с тонкой линией, без бумажки. Бумага — только у физических документов. |
| Орнамент | Только на карточке нового дня. |
| Фото на скотче | Убран скотч: фотобумага и один уголок. |
| Сепия | Убрана с фото-улик (пересобраны в цвете сцены) и с портретов в «Людях». |
| Красный на hover | Наведения — светлая линия или подчёркивание. Красный — улика, связь, противоречие. |

## 3. Титул
«ЗАВЕТЬЕ» с разрядкой .05em, обычный вес; одна строка «Лес хранит несбывшееся»; кнопки прямым шрифтом, наведение — тонкая линия; второй экран «Как проходить английский?» с режимами С поддержкой / Самостоятельно / Погружение; затемнение только под текстом; только медленное появление.

## 4. HUD и игровой экран
Время, тетрадь, меню. Связь — только в прологе. Мысль Анны — книжный курсив, мельче, в одну строку. Подсказка у предмета — прямой шрифт, ромб появляется один раз без пульса, клавиша E только с клавиатурой. Подсказка в первом диалоге — одна инструкция. Подпись к звуку — нейтральная строка.

## 5. Диалоги
Имя — полужирный книжный шрифт, латунный. Текст 19 px, интервал 1.5. Буквица только в главах, легендах, видениях и найденных документах. Номер ответа — маленький моноширинный. Наведение без красного. HUD в разговоре почти исчезает (6 %).

## 6. Тетрадь
Одна бумага, слабая линейка, один красный отступ. Закладки одного цвета; выбранная выступает и отмечена красной ниткой. Заголовки — спокойный шрифт без курсива, подзаголовки без капса и разрядки. Подписи, состояния людей, статусы — обычный шрифт. Доска версии без вращения, с подписями «Тезис → Приколото к версии → Улики в тетради» и метками «подтверждает / противоречит». «Вчера / сегодня» — крупнее, без рамок.

## 7. English Evidence
Раздел «Язык как улика». Вопрос: «Что эта запись позволяет доказать?». Варианты — выводы следователя строками, без ромбов-радиокнопок. После выбора сначала «Версия изменилась», потом заметка. Перевод — по «?». В режиме «С поддержкой» ответ больше не выдаётся заранее: перевод и пояснение открываются после первой попытки. После двух прочитанных записей — одна строка о переносе навыка в обычную речь.

## 8. Цвет
Красный темнее (#7A2A26), яркий — только у новой связи. Синий «учебный» цвет убран. Зелёный — только «версия держится». Бумага: чистый лист и старый документ.

## 9. Анимации
Портреты не «дышат»; вздрагивание только на эмоциональных репликах. Ромб без бесконечного пульса. Один fade 450 мс между местами. Тетрадь открывается коротким движением без поворота.

## 10. Техника
| Пункт | Что сделано |
|---|---|
| head/body | Площадка оборачивает страницу сама. Первым делом страница переносит `<title>`, `<meta>` и стили в `<head>` (`tools/build_artifact.py`). |
| Белая вспышка | Сразу задаётся фон #13110f и светлый текст. |
| Шрифты base64 | Шрифты публикуются отдельными файлами `fonts/*.woff2`; страница уменьшилась с 950 до ~360 КБ. Семейств стало меньше. |
| Типографические переопределения | Четыре роли шрифта вместо десятков ручных назначений. |
| Красный | Разведены роли: нить/улика, опасность (`--danger`), наведение — не красное. |
| Мобильный | Лист диалога ниже (44 % высоты), ответы отдельным листом; тетрадь до 760 px — нижняя навигация. |
| Доступность | Фокус клавиатуры — контрастная светлая рамка с тёмной подложкой; на бумаге — чернильная. |
